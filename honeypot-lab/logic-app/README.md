# Logic App playbook

Build steps are in [../docs/04-alerting-and-automation.md](../docs/04-alerting-and-automation.md), Part B.

After you build the playbook in the portal, open **Logic App > Logic app code view** and save the JSON here as `la-honeypot-notify.json` (remove any secrets or connection IDs first). Also save a screenshot of the designer to `../evidence/logic-app-designer.png`.

`email-template.html` is the email body to paste into the "Send an email" action.
